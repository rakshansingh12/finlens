# FinLens

Scenario-based personal financial decision intelligence. Given a person's
financial profile and a proposed loan, evaluates sustainability across
deterministic calculations and Monte Carlo-simulated future scenarios,
compares alternatives, and explains the evidence via a grounded LLM layer.

## Setup
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then fill in your own values
```
